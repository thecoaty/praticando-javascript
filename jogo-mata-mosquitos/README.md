# AppMataMosquito
Um simples projeto para praticar JavaScript! 
<br>
É um jogo point and click, onde você tem que clickar nas moscas antes que o tempo acabe.

<h3>Instruções</h3>
No inicio o jogador sleciona uma dificuldade, cada uma delas aumenta o tempo em que as moscas permanecem na tela. <br>
Iniciando o jogo, moscas aparecerão aleatoriamente em toda a tela e permanecerão no lugar por um tempo de acordo com a dificuldade, o jogador precisa clickar sob elas para mata-las e pontuar até o tempo acabar, caso não mate alguma perdera um coração de vida, e perde a partida caso não reste pontos de vida.
